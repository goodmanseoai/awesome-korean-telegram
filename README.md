새 채널 제안, 정보 수정, 폐쇄 또는 사칭 신고를 환영합니다. 제출 전에 [기여 가이드](CONTRIBUTING.md)와 수록 기준을 확인해 주세요.

목록 원본은 [`data/channels.json`](data/channels.json)에 있으며 `README.md` 표는 자동으로 생성됩니다.

```bash
python scripts/render_readme.py --check
python scripts/check_links.py
```

## 안전 안내

- 텔레그램 사용자명은 다른 사람에게 이전되거나 탈취될 수 있습니다.
- 채널 이름과 프로필 사진이 같아도 동일한 운영자라는 보장은 없습니다.
- 가상자산 지갑 연결, 송금, 원격제어 앱 설치, 신분증 제출을 요구하면 특히 주의하세요.
- 투자 관련 채널의 글은 투자 자문이나 수익 보장이 아닙니다.
